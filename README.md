# 원판돌리기

네이버 스타일 모바일 원판돌리기(룰렛) 웹앱입니다.

## GitHub Pages 설정 (최초 1회)

404가 나오면 아래 설정이 필요합니다.

1. [Settings → Pages](https://github.com/kim5288403/spinning-wheel/settings/pages) 열기
2. **Build and deployment** → **Source** → **Deploy from a branch** 선택
3. **Branch**: `main` / **Folder**: `/ (root)` 선택 → **Save**
4. 1~2분 후 접속

## 접속 주소

배포 후 아래 주소에서 열 수 있습니다.

**https://kim5288403.github.io/spinning-wheel/**

## 기능

- 옵션 2~8개 설정
- 모바일 터치 지원
- 설정완료 후 원판 돌리기
